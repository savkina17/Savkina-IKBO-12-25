Создание скрипта ./reg
```
#!/usr/bin/env bash
set -euo pipefail

if [ $# -ne 1 ]; then
    echo "Использование: $0 <имя_скрипта>" >&2
    exit 1
fi

src="$1"

if [ ! -f "$src" ]; then
    echo "Файл '$src' не найден" >&2
    exit 1
fi

name=$(basename "$src")
dest="/usr/local/bin/$name"

# Копируем и задаём права/владельца
sudo cp "$src" "$dest"
sudo chmod 755 "$dest"
sudo chown root:wheel "$dest"

echo "Команда '$name' зарегистрирована в $dest"
```

Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

Код скрипта check
```
#!/usr/bin/env bash
set -euo pipefail

if [ $# -lt 1 ]; then
    echo "Использование: $0 <каталог>" >&2
    exit 1
fi

dir="$1"

find "$dir" -type f \( -name '*.c' -o -name '*.js' -o -name '*.py' \) | while read -r f; do
    first=$(head -n 1 "$f")
    case "$first" in
        //*|/\**|\#*|\**) 
            echo "$f: комментарий есть"
            ;;
        *)
            echo "$f: комментария нет"
            ;;
    esac
```

Написать программу для нахождения файлов-дубликатов (имеющих 1 или более копий содержимого) по заданному пути (и подкаталогам).

Код создания, обработки и вывода работы скрипта
```
anton_xax@MacBook-Pro--Daria ~ % nano dups.sh
anton_xax@MacBook-Pro--Daria ~ % chmod +x dups.sh
anton_xax@MacBook-Pro--Daria ~ % mkdir t && echo abc > t/a && echo abc > t/b && echo xyz > t/c
anton_xax@MacBook-Pro--Daria ~ % ./dups.sh t
Дубликаты (hash 0bee89b07a248e27c83fc3d5951213c1):

t/a
t/b
---
anton_xax@MacBook-Pro--Daria ~ % 
```
Вывод состоит только из файлов дупликатов и контрольной суммой перед ними 

Код скрипта duplicates
```
#!/usr/bin/env bash
set -euo pipefail

if [ $# -ne 1 ]; then
    echo "Использование: $0 <каталог>" >&2
    exit 1
fi

dir="$1"

find "$dir" -type f -exec md5sum {} + | sort | awk '
{
    hash=$1
    $1=""
    sub(/^ /, "")
    files[hash] = files[hash] "\n" $0
    count[hash]++
}
END {
    for (h in count) {
        if (count[h] > 1) {
            print "Дубликаты (hash " h "):"
            print files[h]
            print "---"
        }
    }
}'
```



## Задача 8

Написать программу, которая находит все файлы в данном каталоге с расширением, указанным в качестве аргумента и архивирует все эти файлы в архив tar.

Код создания, обработки, архивации и вывода работы скрипта
```
anton_xax@MacBook-Pro--Daria ~ % chmod +x archive_exit.sh 
anton_xax@MacBook-Pro--Daria ~ % ./archive_exit.sh /Users/anton_xax/test txt
tar: Removing leading '/' from member names
a Users/anton_xax/test/txtfile1.txt
Архив создан: archive_txt.tar
anton_xax@MacBook-Pro--Daria ~ % 


```

Код скрипта bash
```
#!/usr/bin/env bash
set -euo pipefail

if [ $# -ne 2 ]; then
    echo "Использование: $0 <каталог> <расширение>" >&2
    exit 1
fi

dir="$1"
ext="$2"
archive="archive_${ext}.tar"

find "$dir" -type f -name "*.${ext}" -print0 | tar --null -cvf "$archive" -T -

echo "Архив создан: $archive"
```
